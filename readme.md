Висновок: Алгоритм Боєра-Мура є безумовним найшвидшим як при успішному пошуку, так і при його відсутності в обох статтях. Його найгірший час (0.000355 sec) все ще значно кращий за найкращий час, показаний Кнутом-Моррісом-Праттом (КМП) (0.001036 sec) та Рабіном-Карпом (0.002673 sec). Така швидкість алгоритму Боєра-Мура обумовлена здатності "стрибати" по тексту (пропускати великі ділянки) за рахунок використання "зміщення поганого символу" та "зміщення доброго суфіксу". Додаткові обчислення Алгоритм КМП і алгоритм Рабіна-Карпа (побудова таблиці префікс-суфіксів для КМП, обчислення хешу для Рабіна-Карпа) роблять їх повільнішими на реальних даних порівняно з Боєром-Муром.

Таким чином, алгоритм Боєра-Мура є найшвидшим з трьох протестованих алгоритмів для пошуку підрядка в наданих текстових даних.
